## How the images were made

The service was started with `python -m skid.interactive --project <project.json> --port 0 --quiet --no-research`. The planner CLI path was deliberately set to a nonexistent program, so **no AI model or web research call was possible or made**. A local script (not published) clicked the workspace's real buttons and saved the browser's own screenshot output:

1. `workspace.png`: default two-pane layout; 3D pane **Fit all**; P&ID pane **Fit sheet**; pointer moved to a corner (so no tooltip shows); screenshot.
2. `pump-skid.png`: 3D pane **Maximize**, **Iso**, toolbar **Focus**, **Fit all**; screenshot. Focus mode hides the toolbar, so the only visible status is the pane badge `Current · r0`.
3. `pid.svg`: fetched over HTTP from the running service at the URL the sheet pane loads (`/artifacts/<build>/pid.svg`). It is byte-identical to the build's `pid.svg`.

The service was then stopped normally.

## Honest observations

- In `workspace.png` the P&ID is shown at Fit-sheet size, so its text is too small to read. Open [`pid.svg`](pid.svg) for the full, readable sheet, including its "PROTOTYPE — NOT FOR DESIGN, PROCUREMENT OR CONSTRUCTION" notes.
- In both screenshots, the 3D labels near the outlet (`L-104`, `L-105`, `OUT-101`) sit close together or overlap slightly. This was left as captured.
- The floating **Ask** button is visible. It was not used.
